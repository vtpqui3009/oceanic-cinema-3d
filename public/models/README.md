# Thả model .glb của bạn vào đây

Scene tự động dùng file có tên khớp với id sinh vật, thay cho model mặc định:

| File                     | Sinh vật                        |
| ------------------------ | ------------------------------- |
| `anglerfish.glb`         | Cá câu vực thẳm (cảnh 4)        |
| `jellyfish.glb`          | Sứa phát quang (cảnh 2)         |
| `squid.glb`              | Mực khổng lồ (cảnh 3)           |
| `fish.glb`               | Cá nhỏ trong đàn (cảnh 1)       |

Trong lúc `npm run dev` đang chạy, thêm/xoá file sẽ tự reload trang.
Nếu model có node tên chứa `lure` / `esca` / `glow`, đèn phát quang sẽ gắn vào node đó.
