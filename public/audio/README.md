# Nhạc của riêng bạn (tuỳ chọn)

Mặc định, nhạc nền được **tạo bằng code** (Web Audio) và đổi theo độ sâu.
Muốn dùng nhạc của mình, thả file vào đây:

| File                          | Dùng cho                                  |
| ----------------------------- | ----------------------------------------- |
| `ambient.mp3`                 | một bản nhạc nền cho cả chuyến lặn        |
| `zone-0.mp3` … `zone-3.mp3`   | mỗi vùng một bản, tự crossfade khi lặn    |

Hiệu ứng âm thanh (khám phá, phát quang, bong bóng…) vẫn được tạo bằng code.
Dùng nhạc có license cho phép (CC0 / CC-BY…) và ghi nguồn trong README chính.
